# 🎵 iPod-Style Music Player

A music player built with **React + TypeScript** featuring an **iPod-style UI** with an **Audiomack-inspired theme**.  
Styled using **Tailwind CSS**, it fetches real songs from the **iTunes Search API** and plays **30-second previews** using the browser’s audio system.  
React Hooks manage state and interactivity with audio feedback for a tactile, app-like experience.

## ✨ Features

- 🎧 Search real songs using the iTunes API  
- ▶️ Play / Pause 30-second previews  
- ⏭️ Skip & navigate tracks  
- 📱 iPod-style circular UI  
- 🎨 Audiomack-inspired theme  
- 🔊 Audio feedback for button interactions  
- 📂 Menu system for Description, Favorites & Playlists  
- ❤️ Save songs to Favorites  
- 📁 Save songs to your Playlist  

---

## 🕹 How to Use

1. Type a song name with the artist name or just the artist name into the search bar.  
2. Click on the Search Icon to fetch the songs from the api.
3. Press Play/Pause Icon to hear the 30-second preview or pause it.  
4. Use the forward and backward icon to skip through the songs.  
5. Save songs to Favorites or Playlists by clicking on the heart icon to add the song to favorites or the 3 lines beside it to add it to your playlist.
6. Open the **Menu** to switch between **Description, Favorites, and Playlists**.
7. press enter to go into the description/playlist/favorites.
8. press the back arrorw to exit.
9. press the home icon to go back to the front page.
